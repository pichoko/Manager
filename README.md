# Project Manager (نسخه اسکلت - v0.1.0)

این نسخه فقط برای تست مسیر ساخت برنامه است؛ هنوز هیچ قابلیت واقعی (پروژه‌ها، مالی و...) نداره.
هدف این نسخه فقط اثباته که مسیر «از کد تا فایل exe. قابل‌اجرا روی ویندوز» درست کار می‌کنه.

## قبل از شروع

مطمئن شوید Node.js نصب است. یک PowerShell یا Command Prompt باز کنید و بزنید:

```
node -v
```

اگر یک عدد نشون داد (مثلاً v20.11.0)، آماده‌اید.

## مرحله ۱ - نصب پکیج‌ها (فقط بار اول)

این پوشه را از حالت zip خارج کنید (Extract All)، بعد داخل همون پوشه یک ترمینال باز کنید
(می‌تونید داخل پوشه راست‌کلیک کنید و «Open in Terminal» یا «Open PowerShell window here» رو بزنید)
و این دستور رو بزنید:

```
npm install
```

این کار ممکنه چند دقیقه طول بکشه (بسته به سرعت اینترنت). فقط یک‌بار لازمه، مگر این‌که فایل
package.json تغییر کنه.

## مرحله ۲ - اجرای آزمایشی (حالت توسعه)

```
npm run dev
```

باید یک پنجره باز بشه با پیام «مدیریت پروژه» و یک دکمه تست. اگر این پنجره باز شد و با کلیک
روی دکمه عدد بالا رفت، یعنی همه چیز درست کار می‌کنه 🎉

برای بستن، همون‌طور که یک پنجره عادی ویندوز رو می‌بندید ببندیدش، یا در ترمینال Ctrl+C بزنید.

## مرحله ۳ - ساخت فایل نصب واقعی (exe.)

وقتی مطمئن شدید حالت توسعه درست کار می‌کنه:

```
npm run build:win
```

بعد از تموم شدن (چند دقیقه طول می‌کشه)، یک فایل نصب‌کننده به اسم
`ProjectManager-0.1.0-setup.exe` داخل پوشه‌ی `dist` ساخته می‌شه. همون فایلیه که می‌تونید
اجرا کنید تا برنامه رسماً روی ویندوزتون نصب بشه (با آیکون روی دسکتاپ).

## اگه به مشکلی خوردید

هر پیام خطایی که در ترمینال دیدید رو دقیقاً (کپی-پیست) برام بفرستید، رفعش می‌کنم.
